# 재작성 우회 관문 실험

지금은 대화 기록이 있으면 **매 턴 재작성 LLM 호출**(측정 중앙값 0.89초)이 일어난다. 독립 질문에는 불필요한 호출이다.
`server/rewrite_gate.py`가 재작성이 필요 없는 질문만 골라 호출을 건너뛰게 한다. **헷갈리면 항상 재작성한다.**

## 관문 규칙
1. 꼬리질문 신호가 있으면 재작성: 시작어("그럼/그건/아니…"), 지시어("거기/방금…"), 형태 변경("영어로/짧게/다시…"), 아주 짧은 발화, "신청 기간은 언제야?"처럼 질문 단어뿐인 발화, 영어 발화
2. 신호가 없으면 원래 발화로 먼저 검색(어차피 하는 일)해서 최고 점수가 τ 이상이면 생략, 미만이면 재작성

켜기: 환경변수 `REWRITE_GATE=1` (기준 점수는 `REWRITE_GATE_TAU`, 기본 0.60). 요청 본문의 `rewrite_gate: true/false`가 있으면 그 값이 우선한다.
서버 로그의 `[timing]` 줄에 `재작성 생략(독립 질문 0.72)`처럼 이유가 찍힌다.

## 파일
- `cases.json` 시험 세트 40개 (꼬리질문 15, 형태 변경 5, 독립 질문 20, dev/test 반반). 꼬리질문의 `expected_question`은 사람이 쓴 것이므로 확인이 필요하다.
- `run_eval.py` 오프라인 평가(과금 없음): τ별 재현율·생략률·검색 적중, dev에서 τ를 고르고 test로 확인
- `bench_ttfb.py` 서버에 직접 보내 "요청 → 첫 글자"를 설정별(off, τ=0.75/0.70/0.65 …)로 비교 (Claude 호출, 비용 약 $0.3~0.6). 서버는 요청 본문의 `rewrite_gate`·`rewrite_gate_tau`로 요청마다 설정을 바꾸고, 응답 헤더 `X-Rewrite-Skip`으로 생략 여부를 알려준다
- `test_gate.py` 관문 규칙 단위 시험 (외부 의존 없음)

## 실행
```
python3 eval/rewrite_gate/test_gate.py                                  # 규칙 시험
server/.venv/bin/python eval/rewrite_gate/run_eval.py                   # τ 곡선 (벡터 DB 필요)
python eval/rewrite_gate/bench_ttfb.py --url http://127.0.0.1:8100/v1/chat/completions --arms off,0.75,0.70,0.65   # 서버 전후 시간
```

## 읽는 법
- **재현율**(꼬리질문·형태 변경 중 재작성으로 보낸 비율)이 핵심이다. 놓치면 앞 맥락 없이 검색해 오답이 난다.
- **생략률**(독립 질문 중 건너뛴 비율)이 높을수록 시간이 줄어든다. 예상 절감 = 생략률 × 0.89초.
- 신호가 없는 어려운 꼬리질문(F07, F10, F14)은 점수에 의존한다. τ를 올리면 잡히지만 독립 질문도 더 재작성하게 된다 — 그 교환 곡선이 결과다.
- 한계: 시험 세트가 40개라 작다. 영어 발화는 이번 실험 대상이 아니다(항상 재작성).
