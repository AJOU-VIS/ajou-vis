# 학습형 재작성 게이트 타당성 시험

**질문**: 지금 규칙(꼬리질문 신호 + 검색 점수 기준 τ)이 못 가리는 꼬리질문을, 작은 분류기가 **같은 재현율에서 더 많이 건너뛰면서** 가려낼 수 있는가?
(`eval/rewrite_gate/`에서 측정한 사실: 신호 없는 꼬리질문의 검색 점수가 0.72로 독립 질문 중앙값 0.71과 같아서, 점수만으로는 재현율 100%에서 생략률이 20%뿐이었다.)

## 라벨 정의 (검색 기준)

발화를 **재작성 없이 그대로 검색**했을 때 정답 문서가 상위 K개(기본 5, 서버가 LLM에 넘기는 개수)에 들어가는가.

| 라벨 | 조건 |
|---|---|
| 0 (건너뛰어도 됨) | 발화 그대로 검색해도 정답 문서가 들어간다 |
| 1 (재작성이 도움됨) | 발화 그대로는 못 찾지만, 독립 질문으로 풀어 쓰면 찾는다 |
| -1 (모호, 제외) | 풀어 써도 못 찾는다 — 검색기 한계라 게이트의 몫이 아니다 |

## 순서

0. 준비: `server/.venv/bin/pip install scikit-learn`
1. **생성** (Claude 호출, 비용 발생): `server/.venv/bin/python eval/gate_learn/gen_data.py --dry-run`으로 프롬프트를 먼저 읽고, `--n-calls 100`으로 실행 (주제 짝은 최대 약 90개, 샘플 약 640개, 약 $1 안팎, 10~20분). 끊겨도 같은 명령을 다시 실행하면 이어서 한다.
2. **라벨·특징 계산** (과금 없음, 5~10분): `server/.venv/bin/python eval/gate_learn/build_features.py`
3. **사람이 훑어보기** (10분): `data/review.csv`의 30개를 읽고 마지막 열에 OK/이상을 적는다. **이상이 20% 넘으면 데이터를 믿지 말고 프롬프트를 고친다.**
4. **학습·평가** (몇 초): `server/.venv/bin/python eval/gate_learn/train_eval.py` → `out/report.md`
5. (선택) 규칙 전체를 분류기가 대신하는 경우: `train_eval.py --population all`

코드 자체 점검(가짜 데이터, API 불필요): `python3 eval/gate_learn/test_gate_learn.py`

## 판정 기준 (결과를 보기 전에 정해 둔 것)

재현율 **98%** 지점에서 분류기(LR 또는 GB)와 규칙의 생략률을 비교한다.

| 결과 | 결정 |
|---|---|
| 분류기가 규칙보다 **+15%p 이상** 높고, 95% 구간 하한이 0 위, 외부 확인(시험 세트의 어려운 꼬리질문 3개)에서 분류기가 규칙보다 많이 놓치지 않는다 | **학습형 게이트로 간다** |
| 차이가 **+5%p 미만**이거나 구간이 0을 포함한다 | 학습형은 이득이 불분명하다. **규칙 + 추측 실행**(재작성과 답변 생성을 병렬로 시작)으로 간다 |
| 그 사이 | 샘플을 더 만들거나(문서를 늘리거나 호출을 반복해) 라벨을 점검한 뒤 다시 본다 |

## 먼저 확인할 것 (결과를 믿기 전에)

- 재작성 필요(라벨 1) 샘플이 **60개 이상**인가. 적으면 구간이 넓어 결론이 안 난다 (주제 짝이 약 90개로 한정이라, 부족하면 꼬리질문 수를 늘리거나 코퍼스 단위를 늘려야 한다).
- `review.csv`에서 어색한 샘플이 20% 이하인가.
- 모호(-1)가 너무 많지 않은가(전체의 30% 넘으면 검색 기준이 데이터와 안 맞는 것).

## 한계

- 데이터는 LLM이 만든 것이다. 실제 음성 인식 결과(오인식, 끊김)나 사용자의 말투보다 쉽거나 깔끔할 수 있다.
- 라벨은 검색 기준이다. 정답 문서가 들어가도 LLM이 틀리게 답할 수 있고, 반대로 정답 문서가 빠져도 답이 맞을 수 있다.
- 시험 세트 외부 확인의 어려운 꼬리질문은 3개뿐이라 참고용이다.
- 특징 중 `cos_q`, `cos_a`, `prev_overlap`은 직전 질문·답변이 필요하다. 서버에 넣을 때 대화 기록과 이전 턴 검색 결과가 이미 있어서 추가 비용이 작지만, 이번 시험은 지연을 재지 않았다.
