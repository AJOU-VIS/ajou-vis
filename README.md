# AJOU-VIS

아주대학교 음성 AI 비서 — 학사규정·행정절차·외국인 학생 행정·캠퍼스 시설 정보를 음성으로 묻고, 근거 조항과 함께 답을 듣는 서비스.

2026-2학기 파란학기제 도전과제 (지도교수: 소프트웨어학과 이상훈 교수님)

## 무엇이 다른가

- 학칙·학사요람·행정 안내 문서를 코퍼스로 구축하고, 답변마다 **근거 조항과 출처를 제시**한다.
- 검색된 문서에 근거가 없으면 **답을 만들지 않고 담당 부서를 안내**한다.
- 웹에서는 아주대 마스코트 캐릭터와 대화하고, 캠퍼스에서는 마스코트 동상 앞 이동형 시제품으로 시연한다.
- 한국어·영어 자동 감지·전환 (중국어는 확장 목표).

## 아키텍처

```
마이크 → VAD → STT → LLM(+RAG) → TTS → 스피커
```

- 기반 파이프라인: [ajou-vis/speech-to-speech](https://github.com/ajou-vis/speech-to-speech) (huggingface/speech-to-speech 포크, Apache-2.0)
- RAG 서버는 OpenAI 호환 엔드포인트로 구현해 파이프라인의 LLM 슬롯에 연결
- 현장 시제품: socket 모드 — 모델은 서버, 소형 보드는 마이크 입력·스피커 재생 클라이언트

## 저장소 구성

```
server/      RAG 서버 (OpenAI 호환 API, 근거 인용·답변 규칙)
corpus/      크롤러, 문서 파싱·청킹, 벡터 DB 구축 스크립트
prompts/     시스템 프롬프트, 페르소나 정의 (ko/en)
eval/        100문항 평가 문항집 실행·채점 스크립트
bench/       구간별 지연 측정, STT/TTS 벤치마크
client/      웹 인터페이스, 보드용 클라이언트
docs/        작업 정리, 회의록 링크, 측정 결과
```

## 팀

|---|---|
| 이다혜 (팀장) | ASR·TTS 서빙 파이프라인, 한/영 전환, 이동형 시제품, 아키텍처 |
| 진주영 | 시스템 프롬프트·근거 응답 규칙, 캐릭터 페르소나·웹 화면, 평가 문항집 |
| 박태연 | 문서 코퍼스·크롤러, 벡터 DB, 검색 정확도, 실시간 정보 연동 |
