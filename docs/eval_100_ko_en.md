# 100문항 평가와 한·영 A/B 테스트 (10/28)

- 담당: 진주영 (프롬프트·평가)
- 요약: 프롬프트 v1.4b와 새 검색 DB(10/25 학사·유학생 28페이지 포함)로 100문항을 한국어·영어 모두 실제 서버 경로에 돌렸다. 정답률은 **한국어 92% · 영어 89%**, 근거 제시율 98% · 99%, 무근거 회피율 100%로 계획서 목표(정답률 1차 70% → 최종 85%, 근거 제시율 90% 이상, 무근거 회피율 100%)를 모두 넘었다. 영어가 3%p 낮은데, 차이는 대부분 영어 질문을 한국어 검색어로 옮겨 검색하는 단계에서 생겼다. 같은 근거를 받으면 두 언어의 답은 같았다.

- 모든 문항에 영어 질문(E열)이 있어, 같은 문항을 두 언어로 물으면 그대로 한·영 A/B 테스트가 된다.

## 2. 실행 조건

- 2026-10-28, 브랜치 `feat/question-bank`, 프롬프트 v1.4b, `claude-opus-5`(effort low), 게이트 임계값 0.5.
- 검색 DB는 10/28에 다시 구축했다 (513조각).
- 러너 `eval/bank/run_bank.py`가 `server/app.py`를 프로세스 안에서 그대로 호출한다 (스모크 테스트와 같은 방식). 문항마다 단일 턴이다.
- 채점은 세 단계로 했다.
  1. Claude 초안: 기대 정답·판정 기준·답·검색결과를 보고 정답(O/X)·근거 제시(O/X/NA)를 매긴다.
  2. 다시 채점: 첫 초안은 검색결과의 문서명만 보고 매겨서, 자료에 있는 수치를 "지어냈다"고 잘못 본 경우가 있었다 (은행 운영시간, 도서관 실시간 좌석 등). X·확신 낮음·한·영이 갈린 51건을 검색결과 본문을 넣어 다시 채점했다.
  3. 검토: 남은 34줄(한·영 판정이 갈림 22, 확신 낮음 7, 확신 높은 X 5)을 원본 자료와 대조해 검토했다. 14건의 판정을 확정하거나 바꿨고, 근거는 `eval/bank/results/…_review.json` 메모에 남겼다.
- 최종 판정은 문항집에 기록했다: 한국어는 `문항집` J·K·L 열, 영어는 `영어 채점` 시트. `집계` 시트는 한국어 기준으로 자동 계산된다.
- 비용(추정): 답변 $5.43 + 채점 $2.29.

## 4. 한·영 A/B

정답 판정이 갈린 문항은 9개다. 영어만 틀린 것이 6개, 한국어만 틀린 것이 3개다.

| 번호 | 질문 요지 | 한국어 | 영어 | 원인 |
|---|---|---|---|---|
| 29 | 장학금은 현금으로 줘? | O | X | 영어 검색어로 지급방법 조항(장학금 지급규칙 제13조)을 못 찾아 보류 |
| 57 | 외국인 학생도 학칙이 똑같이 적용돼? | O | X | 영어 검색어로 외국인학생 규칙 제4조를 못 찾아 보류 |
| 66 | 외국에서 고등학교 나왔는데 입학 자격 돼? | O | X | 영어 검색어로 학칙 제22조(12년 이상)를 못 찾고 유학생 FAQ 지원 자격으로 답함 |
| 80 | 아침 먹을 수 있는 학생식당 있어? | O | X | 영어 검색어로 편의시설의 기숙사 식당 조각을 못 찾아 보류 |
| 89 | 수원역 셔틀 첫차 몇 시야? | O | X | 영어 검색에서 하교 버스 시각 조각(15:10)이 먼저 걸림. 셔틀 표에 등교·하교 표시가 없는 문제와 겹침 |
| 51 | 학부 외국인 학생은 어느 부서에 문의해? | O | X | 부서는 맞았지만 DB에 없는 전화번호를 지어냄 |
| 20 | 복학생도 장학금 받을 수 있어? | X | O | 한국어 검색에서 복학생 제한 조항이 안 걸려 보류 |
| 69 | 외국인 학생 수강·성적은 어디에 물어봐? | X | O | 한국어 답이 학사관리 조항(제4조) 대신 주관부서 조항(제3조)을 골라 답함 |
| 71 | D-2 비자 연장 어떻게 해? | X | O | 한국어 검색에서 구비서류 조각이 안 걸려 서류를 말하지 못함 (지어내지는 않음) |

- **영어만 틀린 6개 중 5개는 검색 단계의 문제다.** 서버는 영어 질문을 한국어 검색어로 옮겨 검색하는데, 그 검색어로 한국어 질문 때와 다른 조각이 걸렸다. 답을 만드는 단계(프롬프트)에서는 차이가 거의 없었다. 같은 근거를 받은 문항은 두 언어의 답이 같았다 (39번 등).
- 10/28에 번역 지시만 바꿔 비교해 봤다 (88문항, 기대 문서가 검색 상위 3개 안에 든 수: 한국어 원문 55 · 지금 번역 53 · 짧은 번역 53). 번역 방식만 바꿔서는 나아지지 않아 번역 지시는 그대로 두었다. 영어 원문과 번역 검색어로 함께 검색해 합치는 것처럼 검색 쪽을 바꾸는 방법을 다음 후보로 둔다.
- 영어 답은 더 길고(평균 44단어, 목표 30) 더 느리다(중앙값 +1.5초 — 번역 호출 한 번). 서버 문장 상한이 영어 답 4건을 잘랐다.
