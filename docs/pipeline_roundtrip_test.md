# 파이프라인 음성 왕복 테스트 기록

- 일시: 2026-09-23
- 환경: MacBook (Apple M4, 16GB RAM), 로컬 실행 (`speech-to-speech local`)
- 실행 스크립트: 포크 레포의 `run_local_ko.sh` (팀원 재현용)

## 결과 요약

**영어·한국어 모두 음성 질문 → 음성 응답 왕복 성공.** 2주차 점검 기준 "음성 왕복 1회 이상 성공" 달성, 벤치마크로 확정한 STT(whisper-large-v3-turbo)가 실제 파이프라인에서 동작함을 검증.

## 1차: 레포 기본 구성 (영어)

- 구성: Mac 프리셋 — Parakeet TDT STT + Qwen3-4B 4bit(MLX) LLM + Qwen3-TTS 6bit(MLX)
- "Hello, what can you do?" → 정확 인식 → 응답 생성 → TTS 첫 오디오 0.19초(TTFA)
- 특이사항: 불명확한 발화 조각이 러시아어(키릴 문자)로 오인식됨 — Parakeet이 유럽 25개 언어 전용이라 발생. **한국어 STT 교체가 필수임을 보여주는 실증 사례.**

## 2차: 한국어 구성 (확정 모델)

- 구성 변경: `--stt mlx-audio-whisper` (기본 모델이 whisper-large-v3-turbo) + `--language auto`
- "안녕 자기소개해줘", "아주대학교에 대해 소개해줘" → 한국어 정확 인식
- 언어 자동 감지 → 한국어 응답 → 한국어 TTS 재생 (TTFA 0.19초, 영어와 동일한 응답성)

## 관찰 사항 (다음 단계 근거)

1. **RAG 없는 LLM 단독 응답은 부정확하다** — "아주대는 한국의 대표적인 공과대학"(실제는 종합대학) 같은 근거 없는 응답 확인. RAG 연동 후 before/after 비교 자료로 활용 예정.
2. **로컬 4bit Qwen3-4B의 한국어 표현이 어색함** ("네가 도와줄 수 있는 친절한 AI 어시스턴트예요") — 실서비스는 API LLM + 시스템 프롬프트(치토 페르소나, 프롬프트 담당 파트)로 대체되므로 로컬 테스트 한정 문제. 자연스러운 한국어 응답 품질은 프롬프트 v1 적용 단계에서 개선.
3. 첫 실행 시 모델 다운로드 약 9GB(STT+LLM+TTS+Whisper), 디스크 여유 확인 필요.
4. 포트 8765가 다른 서비스와 충돌할 수 있어 8766 사용.

## 재현 방법

```bash
# 포크 레포에서 (Apple Silicon)
./run_local_ko.sh   # 새 터미널에서 실행, Ctrl+C로 종료
```

## 남은 작업

- 구간별 지연 측정 코드 (VAD→STT→LLM 첫 토큰→TTS 첫 오디오 타임스탬프)
- 시스템 프롬프트 v1 주입 테스트 (프롬프트 주입 구조 결정 후)
